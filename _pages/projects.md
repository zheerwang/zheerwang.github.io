## ASSERT — Monitoring & Evaluation for LLM Coding Agents

**Python · LLM Agents · Evaluation · Software Engineering**

A monitoring and evaluation framework designed to make LLM coding agents more reliable and interpretable.

- Built a four-stage pipeline for **task decomposition, high-recall assumption extraction, semantic deduplication, and verification**.
- Generated structured audits with assumption categories, code evidence, rationales, and alternative implementation choices.
- Evaluated the system on a **60-record benchmark across five coding domains**.
- Achieved **93.7% precision** and **81.9% operational recall**.
- Increased validated findings from **213 to 481**, a **126% improvement**.

## FinMA-RAG — Multi-Agent Retrieval & Reasoning for Financial QA

**Python · LangGraph · FAISS · BM25 · ColBERT-v2 · RAG**

A multi-agent retrieval and reasoning system for answering questions over SEC 10-K and 10-Q filings.

- Built a hybrid retrieval pipeline combining **BM25 and dense vector search**.
- Added LLM-based query rewriting and **ColBERT-v2 reranking**.
- Designed Retriever, Analyst, Calculator, and Synthesis agents using **LangGraph**.
- Added deterministic tool routing and iterative verification for more reliable answers.
- Improved **Recall@5 from 0.53 to 0.76**.
- Improved FinanceBench QA accuracy from **19.3% to 44.0%**.
